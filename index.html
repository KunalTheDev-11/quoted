AiRepository.kt • SituationMatchResult

🎯 AI Situation Matcher Engine

VOICE OR TEXT INPUT

Life doesn't happen in rigid dropdown categories—it happens in specific, high-stakes, or quiet human moments. In Quoted, users type or speak any real-life situation into the Situation Matcher.

6-STEP EXECUTION PIPELINE:
  1. User inputs a natural-language situation via keyboard or voice prompt.
  2. Input is dispatched to AiRepository.matchSituation(situation, candidateQuotes).
  3. Gemini evaluates candidate original quotes and selects/crafts the best match + a 1-line psychological reasoning statement.
  4. JSON response is parsed into SituationMatchResult(quoteText, category, reasoning, isOriginal).
  5. If offline, a local keyword-matching algorithm executes instantaneously with zero error dialogs.
  6. Displayed in an elevated card with "Share Match 📸" and "Save to Vault ❤️" actions.

2. Room Persistent Database Schema & Kotlin DAO Signatures

Quoted utilizes Android Room Database (AppDatabase) on version 3 with destructive fallback migration disabled for data safety and offline queue durability.

Entity 1: FavoriteQuote favorite_quotes
  • • id: Long (Primary Key, Auto-Generate)
  • • quoteText: String (Not Null)
  • • category: String
  • • language: String
  • • part: Int
  • • savedAt: Long (Timestamp in ms, default System.currentTimeMillis())
@Dao
interface FavoriteQuoteDao {
    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insertFavorite(favoriteQuote: FavoriteQuote)

    @Delete
    suspend fun deleteFavorite(favoriteQuote: FavoriteQuote)

    @Query("DELETE FROM favorite_quotes WHERE quoteText = :quoteText")
    suspend fun deleteFavoriteByText(quoteText: String)

    @Query("DELETE FROM favorite_quotes")
    suspend fun deleteAllFavorites()

    @Query("SELECT * FROM favorite_quotes ORDER BY savedAt DESC")
    fun getAllFavorites(): Flow<List<FavoriteQuote>>

    @Query("SELECT EXISTS(SELECT 1 FROM favorite_quotes WHERE quoteText = :quoteText)")
    fun isFavorite(quoteText: String): Flow<Boolean>

    @Query("SELECT * FROM favorite_quotes WHERE quoteText = :quoteText LIMIT 1")
    suspend fun getFavoriteByText(quoteText: String): FavoriteQuote?
}
Entity 2: SeenQuote seen_quotes
  • • id: Long (Primary Key, Auto-Generate)
  • • quoteText: String (Unique Index for duplicate checking)
  • • timestamp: Long
@Dao
interface SeenQuoteDao {
    @Insert(onConflict = OnConflictStrategy.IGNORE)
    suspend fun insertSeenQuote(seenQuote: SeenQuote)

    @Query("SELECT quoteText FROM seen_quotes")
    suspend fun getAllSeenQuoteTexts(): List<String>

    @Query("SELECT COUNT(*) FROM seen_quotes")
    fun getSeenQuoteCount(): Flow<Int>

    @Query("DELETE FROM seen_quotes")
    suspend fun clearAllSeen()
}
Entity 3: CachedQuote cached_quotes
  • • id: Int (Primary Key, Auto-Generate)
  • • quoteText: String
  • • categoryDisplayName: String
  • • categoryFolderName: String
  • • languageDisplayName: String
  • • languageCode: String
  • • part: Int
  • • timestamp: Long
@Dao
interface CachedQuoteDao {
    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insertCachedQuotes(quotes: List<CachedQuote>)

    @Query("SELECT * FROM cached_quotes WHERE languageCode = :languageCode")
    suspend fun getCachedQuotesForLanguage(languageCode: String): List<CachedQuote>

    @Query("SELECT * FROM cached_quotes WHERE categoryFolderName = :category AND languageCode = :languageCode")
    suspend fun getCachedQuotesForCategoryAndLanguage(
        category: String,
        languageCode: String
    ): List<CachedQuote>

    @Query("SELECT COUNT(*) FROM cached_quotes")
    suspend fun getCachedQuoteCount(): Int

    @Query("DELETE FROM cached_quotes WHERE quoteText = :quoteText")
    suspend fun deleteCachedQuote(quoteText: String)
}

4. Offline Pre-Fetching & Performance Architecture

  • Pre-Seeded Original Library (`PreSeededQuotes.kt`) Over 300 pre-bundled original quotes across 10 curated categories available the instant the APK is installed.
  • 100-Quote Horizon Preload Queue Background coroutine workers on Dispatchers.IO pre-fetch upcoming quotes into local memory and Room DB (`cached_quotes`).
  • Physical Wallpaper Fallback (`WallpaperRepository.kt`) 25 bundled high-resolution wallpapers stored locally in Android drawable resources.
  • Coil Memory & Disk Cache Keying Pre-decodes background images off the main thread so card swiping stays locked at 120 FPS.
  • Stutter-Free Ad Preloader (`NativeAdPreloader.kt`) Preloads Google Native Ads asynchronously in the background for seamless insertion every 8th scroll without frame drops.

1. Introduction & Scope

This Privacy Policy governs your use of the Android mobile application Quoted (package identifier: com.kunalthedev.quoted), developed and published by KunalTheDev ("Developer", "we", "us", or "our"). Quoted is built around the core philosophy that "Every quote is original" and "Quotes matched to your situation, not a category."

Quoted is architected as an offline-first, privacy-by-design application. You are not required to register an account, log in, or provide personally identifiable information (such as your name, email address, phone number, or billing details) to access or use Quoted.

2. Information We Collect & Local Device Storage

All primary user data generated while using Quoted is stored strictly locally on your Android device inside the application's private sandboxed directory using the Android Room Persistence Library (AppDatabase v3) and Android SharedPreferences:

  • Mental Vault / Saved Favorite Quotes (favorite_quotes table): Stores quotes you explicitly save to your Mental Vault, including quoteText, category, language, part, and the local save timestamp (savedAt).
  • Seen Quotes History (seen_quotes table): Stores the text and timestamp of quotes you have already explored so the recommendation stream avoids showing duplicate quotes.
  • Offline Horizon Cache (cached_quotes table): Stores pre-fetched original quotes locally on your device to guarantee uninterrupted offline reading.
  • Personalization & Duel Preferences (AiContextPreferences & QuoteDuelPreferences): Stores your chosen theme mode (Dark, Light, Sepia), active language selection (English or Hinglish), haptic vibration preference, auto-advance slideshow timer setting, contextual mood/weather selections, and your Daily Quote Duel votes.

We do not maintain any proprietary external server that collects, syncs, or harvests your Mental Vault, reading history, or local preferences.

3. AI Situation Matcher & Google Gemini API Processing

When you voluntarily use the AI Situation Matcher feature and type or speak a description of your real-life moment (for example, "I have an interview in an hour" or "My best friend just moved away"), that situational text prompt and candidate quotes are transmitted securely over encrypted HTTPS (TLS) to the Google Gemini Generative AI REST API (https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent).

  • Purpose of Processing: Your prompt is used exclusively to evaluate candidate original quotes, select or craft the best situational match, and generate a 1-line explanation (SituationMatchResult) describing why the quote fits your moment.
  • No Identity Linkage or Resale: Situational prompts are transmitted without any personal identifiers (no name, email, or account ID) and are never sold, rented, or stored on developer-owned servers.
  • Offline Fallback: When your device is offline, Quoted processes your situation prompt 100% locally on-device using its built-in keyword-matching algorithm without making any network request.

4. Device Permissions Explained

Quoted requests only the minimal Android permissions required to deliver its features:

1. Internet Access (INTERNET & ACCESS_NETWORK_STATE) Required to communicate securely over HTTPS with the Google Gemini API for live Situation Matching and to preload Google AdMob Native Ads.
2. Microphone / Speech Recognition (Optional Voice Input) Used only when you tap the microphone icon in the Situation Matcher to dictate your situation via Android's speech recognizer. Quoted never records, stores, or uploads raw audio files. Text-to-Speech (TTS) playback in the Mental Vault runs locally via android.speech.tts.TextToSpeech.
3. Vibration / Haptics & Notifications (VIBRATE / POST_NOTIFICATIONS) Used to provide tactile haptic feedback during quote exploration (controllable in Settings → Haptics & Reading) and optional scheduled Daily Quote Notifications.
4. Media Sharing & Vault Export (Android System ACTION_SEND) When you export HD graphics from the Social Studio (SocialImageExporter.kt) or back up your Mental Vault, Quoted uses Android's native system share sheet (ACTION_SEND) without requiring broad access to your private photos.

5. Third-Party Services & SDKs

Quoted integrates the following third-party services governed by their respective privacy policies:

  • Google Gemini Generative AI API: Used for real-time situational quote matching. Governed by the Google APIs Terms of Service and Google Privacy Policy.
  • Google AdMob (`NativeAdPreloader.kt`): Used to preload and display native advertisements every 8th scroll within the quote stream. The Google Mobile Ads SDK may collect your device's Google Advertising ID, coarse IP-based location, device diagnostics, and ad interaction metrics for ad delivery and fraud prevention. Users can reset or delete their Advertising ID at any time in Android system settings (Settings → Google → Ads).

6. User Data Control, Retention & Deletion

Because all personal app data is stored locally on your device, you have complete, immediate control over its retention and deletion at any time:

  • Delete Saved Favorites: Open the Mental Vault (SavedQuotesSheet.kt) to delete individual quotes or clear all saved favorites (deleteAllFavorites()).
  • Reset Recommendation Memory: Open Settings → Data Vault → Reset Recommendation Memory to permanently clear your seen quotes history (SeenQuoteDao.clearAllSeen()).
  • Reset All Settings to Default: Open Settings → Data Vault → Reset All Settings to Default to wipe all local preferences, mood/context weights, and Daily Quote Duel state.
  • Uninstall Application: Uninstalling Quoted or clearing app storage via Android System Settings permanently erases the entire local SQLite Room database and all preferences from your device.

7. Children's Privacy & Security

Quoted is a general-audience wisdom and inspiration application and does not knowingly collect personal information from children under the age of 13 (or the applicable age of digital consent in your jurisdiction). All network traffic to third-party APIs is encrypted via HTTPS/TLS, and local Room database files are protected inside Android's application sandbox.
